2. STEP-BY-STEP GUIDE: PUBLISHING A NEW POST
--------------------------------------------------------------------------------
Step 1: Copy the Starter Template
  cp template.md posts/your-article-slug.md

Step 2: Fill Out the Frontmatter at the Top
  ---
  title: "Your Post Title Here"
  slug: "your-article-slug"
  date: "2026-10-31"
  lastUpdated: ""
  excerpt: "A short 1-2 sentence preview hook."
  tags: ["Technology", "Engineering"]
  coverImage: "https://images.unsplash.com/photo-..."
  author: "Ugandhar"
  published: true
  ---

Step 3: Write Markdown Content
  Use ## for sections, ### for subsections, ```lang for code blocks, and
  standard markdown tables and blockquotes.

Step 4: Preview Locally
  npm run dev
  Visit http://localhost:3000/posts/your-article-slug

Step 5: (Optional) Auto-Sync Dates
  npm run update-dates

Step 6: Commit & Push to GitHub
  git add posts/your-article-slug.md
  git commit -m "feat(blog): publish your article title here"
  git push origin main

Step 7: Instant Search Engine Submission
  npm run indexnow


3. AUTOMATIC DATE & TIME DETECTION
--------------------------------------------------------------------------------
- If 'lastUpdated' in frontmatter is left empty or omitted, the system
  automatically detects the file modification timestamp (mtime) or git commit date.
- 'date' displays as the publication date (e.g. October 31, 2026).
- 'lastUpdated' displays as a subtle badge 'Updated Oct 31, 2026' if modified.
- To audit all dates across markdown files, run:
  npm run update-dates
